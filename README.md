# BoltLog

Flutter app + Firebase. Admin tools live on **GitHub Pages** (built from `website/`).

## Admin website (open in your browser)

**Live site:** [https://boltlog-admin.github.io/BoltLog/](https://boltlog-admin.github.io/BoltLog/)

That URL is served after [Deploy website to GitHub Pages](https://github.com/Boltlog-admin/BoltLog/actions/workflows/deploy-website-github-pages.yml) finishes successfully. First-time setup: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

**Pin it on the repo home:** on GitHub open **About** (gear) → **Website** → paste the same URL so it shows next to the repo description.

You cannot run the site from the “Code” file list alone—the built app is static files on Pages, not the raw source.
